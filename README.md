# 🛡️ TruthLens: AI Misinformation & Credibility Intelligence Engine

TruthLens is a production-grade, evidence-aware misinformation analysis dashboard built for hackathons. It evaluates articles across multiple distinct pillars: Machine Learning classification, linguistic risk detection, live evidence retrieval, and structured LLM reasoning.
